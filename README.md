# Featured Projects

## Radar & Remote Sensing

### GPR Signal Processing
Research work focused on improving the quality of Ground Penetrating Radar data through signal-processing techniques.

**Methods explored:**
- Mean Trace Subtraction
- SVD / EVD
- Wavelet Transform
- f-k filtering
- Radon Transform
- Deterministic Deconvolution
- Hybrid SVD–Wavelet processing

**Focus:** SNR improvement, clutter suppression and subsurface target visibility.

# FPGA & Embedded ML

### FPGA-Based 1D CNN Accelerator

Implementation of a lightweight 1D CNN architecture for hardware inference on Intel FPGA platforms.

**Target platforms:**
- Intel MAX 10 / DE10-Lite
- Intel SoC FPGA / DE1-SoC

**Technologies:**
- SystemVerilog
- Quartus Prime
- ROM-based weight storage
- Parallel multiply-accumulate operations
- Fixed-point hardware implementation
- CNN inference acceleration

**Application:** collision-probability prediction using satellite conjunction data.
